# 固定した実験証拠

回帰試験が再採点する過去の実モデル出力だけを保存する。合成fixtureや新しいモデル受入結果とは区別する。
元のJSONは内容を変更せずgzip圧縮し、manifest.jsonに非圧縮バイト列のSHA-256とサイズを記録した。
隣のMarkdownは結果の要約。詳細は `gzip -dc <file.json.gz>` で読める。
新規の実行結果はartifacts/またはexamples/**/results/へ置き、検証に必要な固定証拠を選んだ場合だけここへ追加する。
通常のverifyではモデルを呼ばず、この証拠を再採点する。生出力の省略やskipで検証期待値を弱めない。
