## 実行前に固定する計画

| 方式 | 適用確認・資料網羅の指示 | 出力順 |
|---|---|---|
| baseline | 既存v5 | 資料→評価→説明→判定 |
| instruction | 前回候補から取り出した指示 | 資料→評価→説明→判定 |
| order | 既存v5 | 評価→資料→説明→判定 |
| combined | instructionと同じ指示 | 評価→資料→説明→判定 |

指示の因子は施行時点/範囲/権限、CLAIM_NOT_VALIDの扱い、全評価規程と存続観測方針の資料網羅を含む。
前回の「After writing assessments, include」を「Include」に置換して順序依存を除く。意味上の規則は追加しない。
順序因子は出力順の文とschemaのproperty/required順を同時に変える。欄・値域・制約は同じ。
そのためcombinedは前回候補とバイト同一ではなく、順序の寄与をschemaだけと文章だけに分離する試験でもない。
両指示間の差分が、どちらの順序でも同じになることを部分試験で確認する。

新規4資料群16文書16問と既知8問を各2反復・4方式で192回答、抽出4回共用、最大196呼出し。
新規はORからANDへの施行切替、2段階の改訂と観測章存続、全文撤回と観測別文書化、範囲別存続と未承認案。
同じ時刻境界の対と、同じ資料内の複数設問は相関する。新規資料は同一作成者の合成資料で、独立実資料ではない。
既知はPC01/CV04/CC02/AR03/NR02/CP02/RV03/CB03。以前の失敗6件を回帰試験で保存する。
4通りのWilliams順で、各群・各反復内の位置と隣接順を均等化する。2並行、呼出し120秒、再抽選/修正/回復なし。

主指標は判定、適用資料集合、許可規程評価集合/結果、既存監査の全一致。初回失敗を分母から除かない。
新候補を改善として保持するには、全呼出し完了、既知8問の両反復成功、各群の主指標と判定がv5以上、誤許可/撤回資料混入0、
未見で改善数>悪化数、かつ新規2資料群以上で純改善が必要。1件だけの差に基づく前回より広い保持基準で、実測前に固定する。
以前の候補の保存・採否は上書きしない。全方式同点や1資料群だけの改善なら新たな採用なし。既定v5は常に維持する。

因子ごとに他方を固定した2比較、平均差、差の差を既知/未見別に報告する。
例: 指示の平均差=((instruction-baseline)+(combined-order))/2、相互作用=combined-instruction-order+baseline。
集計は正解率差。因子への記述的支持は未見の2比較に負の純差がなく少なくとも一方が正、2資料群以上で合計純差が正、
対応する判定が低下せず誤許可/撤回資料混入もない場合だけ。統計的因果・有意差と呼ばない。
支持が混在したら条件別に報告し、合計で回帰を隠さない。全て満点なら寄与不明とする。

## 作業と完了条件

1. 既存指示/入力/共通機構の確認、失敗再現と因子分離・順序・集計/採否の部分試験。
2. SQLite結合、verify/build後に全実験コード・指示・資料・期待値・判定条件を固定。
3. 固定コードで1回の実モデル比較。全初回応答、説明、抽出、費用を点検。実行中の編集なし。
4. キャッシュ再生で追加呼出し0と結果不変、新規SQLite入力と全採点の再現試験。
5. 生結果、採否、限界、進捗を保存。最終verify/build、意味判断代替/担当外変更の差分点検、commit/push。
