## Eumenes Memory

The locally generated `vendor/eumenes-memory` type/JS distribution is pinned independently at package source version 0.3.6. Its unchanged file hashes and archive provenance remain in the vendor manifest and pin. The owner's MIT confirmation covers this fixed distribution. `legal/eumenes-memory.LICENSE` preserves the Eumenes Memory contributors notice from the public Memory project; the pack process adds it to the Memory tarball without changing the pinned vendor bytes.

World tarballs contain compiled JS, declarations, the distribution manifest and these notices. Evaluation corpora, scraped material, fixtures, API keys, product databases and research outputs are not included. Their external source terms are not replaced by the project's MIT license. Development dependencies retain their own licenses; they are not bundled into the World runtime tarball.
